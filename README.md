# First Mix

An iPad-ready DJ learning PWA. Real Web Audio mixing, guided lessons, an openly licensed starter catalog, local audio imports, and offline practice. No backend or runtime dependencies.

## Run

```sh
npm start
```

Open http://localhost:4173. On iPad, use the deployed HTTPS URL in Safari → Share → Add to Home Screen. Audio starts only after a tap. `localhost` on an iPad refers to the iPad itself, not this Mac; the hosted HTTPS app is the installation path.

## What works

- Two independent decoded audio decks, play/pause, waveform seek, set/return cue, ±20% tempo, phase/tempo sync, 4/8/16-beat loops, 25 ms nudges, low/mid/high EQ and master volume.
- Equal-power crossfader with ramped gain changes and master headroom/compression.
- Four event-driven learning exercises. Completion saves on this device.
- Seven starter tracks: two original practice loops, two Toucan Music house tracks, two Alex Morgan Afrobeat/amapiano tracks, one 1000 Handz hip-hop instrumental.
- Catalog filters by source/style. Full track credits, license URLs and direct downloads in Music sources.
- MP3/WAV/M4A import into IndexedDB; file validation, limits, deletion, search and manual BPM/downbeat editing. Files never upload.
- Manifest, maskable icons, service worker, offline app shell/practice audio. Catalog tracks cache after loading.
- Keyboard controls and labeled touch controls. Layouts for landscape, portrait and narrow windows.

## Important limits

Tempo adjustment changes pitch; pitch-preserving time stretching is future work. Catalog BPM and beat-zero values are editable estimates, not professionally analyzed grids. There is no dedicated headphone cue bus, scratching, recording/export or MIDI yet. Playback pauses when the app goes into the background. Browser storage can be evicted; keep original files. Heavy tracks need physical iPad memory/latency testing.

Spotify audio is not integrated: the public API prohibits mixing/overlap, while licensed DJ access is limited to partner integrations. The app links to supported options without presenting a fake connection. See the plan for sources and the external dependency.

The Alex Morgan tracks are labeled wholly/partly AI-generated by the uploader; that fact appears in the crate and credits. No track is represented as a famous DJ's recording or endorsement. The Afrobeat track is labeled with its actual source genre rather than being misrepresented as a commercial Afrobeats hit.

## Verify

```sh
npm test
npm run check
```

`scripts/browser-check.mjs` exercises Chromium and WebKit with Playwright (a development-only tool). It covers playback, cue lessons, beatmatching, imported-file persistence, grid changes, offline startup, real OfflineAudioContext rendering and responsive overflow. Install Playwright separately or set `FIRSTMIX_PLAYWRIGHT` to an installed module's absolute path; run with the local server active. `FIRSTMIX_URL` optionally changes the target origin.

```sh
node scripts/browser-check.mjs
```

## Source

- `dist/app.js`: views, event handling and practice flow.
- `dist/audio.js`: two-deck Web Audio engine.
- `dist/core.js`: pure math, waveform envelope and lesson rules.
- `dist/storage.js`: IndexedDB and local progress.
- `dist/sw.js`: app-specific offline caching.
- `dist/catalog.json`: audio metadata, waveform peaks and credits.
- `dist/assets/licenses.json`: per-file source, license, verification date, hash and AI disclosure.
- `scripts/prepare-assets.py`: original audio/icon generator and catalog metadata preparation. Requires ffmpeg/ffprobe; does not modify downloaded MP3s.

For your own server, serve `dist/` over HTTPS with correct JavaScript, JSON, manifest and audio MIME types. Do not cache `sw.js` indefinitely; increment its cache version whenever releasing updated assets. For a larger catalog, use object storage/CDN with appropriate CORS, authenticated administration and license/attribution metadata. Runtime imports currently remain local to each browser.

Track licenses cover the recordings, not the whole application. Preserve all credits when hosting. See [Music credits](dist/assets/MUSIC-CREDITS.txt), [the project plan](docs/PROJECT_PLAN.md) and [design notes](docs/DESIGN.md).
