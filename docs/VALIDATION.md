# Validation — November 18, 2026

## Automated checks

- `npm test`: 13 passing tests covering equal-power gain, beat phase wraparound, ordered lesson events, transition prerequisites, looping/EQ prerequisites, real waveform peaks, title escaping, pause/resume/rate continuity, loop release, sync limits, PWA assets, collection coverage and licensed-file hashes.
- `npm run check`: all five production JavaScript modules/service worker parse successfully.
- Real browser checks in Chromium and desktop WebKit: deck playback time advances, cue and beatmatch lessons complete through the interface, progress survives reload, imports save/reload/load, grid edits update BPM, style filters return the correct tracks, no horizontal overflow at 1440/1024/768/390 pixels, and no uncaught page errors.
- A real `OfflineAudioContext` renders both decks and a blend with nonzero RMS; the two sources produce different samples; a bass EQ cut reduces measured signal energy.
- Chromium offline test: service worker installs, app reloads with networking disabled, and practice audio plays. The five catalog MP3s are also decoded by a real browser.
- A WebKit import-storage defect was found and fixed: persist raw audio bytes in IndexedDB, reconstruct a Blob when loading, and capture file bytes before clearing the picker. Import failures display a recoverable message.

Browser check output/screenshots are generated under ignored `artifacts/browser/`; the reproducible test is `scripts/browser-check.mjs`.

## Visual checks

Design-taste-frontend inspector at desktop, iPad landscape, iPad portrait and phone widths: zero failures. Lint: zero failures. Look-and-fix loop reduced deck height, kept the crossfader near transport controls, improved label sizes, aligned the lesson pane, and removed repeated boxed icons. Screenshots were reviewed.

Remaining inspector warnings are deliberate:

- Compact metadata (time, BPM units and secondary labels) uses 11–12 px while task controls/instructions use 13–14 px. The interface is a dense console; physical iPad accessibility review is still required.
- The lesson pane spans the full height of the decks plus mixer, while each deck is only one block within that group. The inspector compares the deck bottoms to the entire spanning pane.
- The data hue is drawn into actual waveform canvases, which the DOM color classifier does not detect. Amber samples and neutral comparison samples are visible in the reviewed screenshots.
- Lesson context labels are repeated app state, and zero-padding formats playback time; lint’s generic eyebrow/numbering warnings do not apply to those uses.

## Limits of this verification

Desktop WebKit is not a physical iPad. Home-screen installation, real touch ergonomics, VoiceOver, browser text zoom, sustained playback latency, memory/thermal behavior, Bluetooth and USB-C route changes remain device checks. No claim of App Store readiness or professional DJ latency is made.

Catalog music is licensed according to its individual source pages; the app preserves credit and disclosure records. Human listening/curation and professionally verified grids remain future catalog work. The two Alex Morgan tracks are explicitly marked AI-generated by their uploader; the app preserves that disclosure.
